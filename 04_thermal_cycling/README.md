# NPT Thermal Cycling Simulation

This directory contains the atomic model, LAMMPS input file, intermediate
atomic configurations, analysis scripts, and source data used for the NPT
thermal cycling simulation of the Fe–Cr–C–Mn–Si–W alloy system.

## 1. Simulation system

The initial model contains 16,148 atoms and was constructed by expanding a
body-centered cubic structure. Atomic interactions were described using the
trained Fe–Cr–C–Mn–Si–W deep potential provided in:

```text
../02_trained_potential/graph_200000.pb
```

The atomic type mapping used in the LAMMPS data and trajectory files is:

```text
1 Fe
2 Cr
3 C
4 Mn
5 Si
6 W
```

The corresponding atomic masses are:

| Type | Element | Atomic mass (g/mol) |
|---:|---|---:|
| 1 | Fe | 55.845 |
| 2 | Cr | 51.9961 |
| 3 | C | 12.011 |
| 4 | Mn | 54.938 |
| 5 | Si | 28.0855 |
| 6 | W | 183.84 |

## 2. Simulation conditions

The simulation was performed using LAMMPS with the following settings:

- Unit system: `metal`
- Atom style: `atomic`
- Boundary conditions: periodic in the x, y, and z directions
- Thermodynamic ensemble: NPT
- External pressure: 0 bar
- Timestep: 0.001 ps
- Thermostat damping parameter: 0.1 ps
- Barostat damping parameter: 1.0 ps
- Initial temperature: 300 K
- Maximum temperature: 1850 K
- Initial-velocity random seed: 12345
- Trajectory output interval: 1000 molecular dynamics steps

The conjugate-gradient method was used for the initial energy minimization.

## 3. Thermal cycling procedure

The thermal cycling simulation consisted of the following stages:

| Stage | Temperature condition | Number of steps | Duration |
|---|---|---:|---:|
| Initial equilibration | 300 K | 20,000 | 20 ps |
| Heating | 300–1850 K | 100,000 | 100 ps |
| High-temperature holding | 1850 K | 50,000 | 50 ps |
| Cooling | 1850–300 K | 100,000 | 100 ps |
| Final equilibration | 300 K | 20,000 | 20 ps |

The total molecular dynamics simulation time, excluding energy minimization,
was 290 ps.

## 4. Directory contents

### Simulation input and initial structure

- `in.simp_npt_cycle`: LAMMPS input file for the complete NPT thermal cycling
  simulation.
- `simp_20x20x20.data`: Initial atomic configuration.
- `make_simp_bcc.py`: Python script used to construct the initial
  body-centered cubic atomic model.

### Simulation log and atomic configurations

- `log_simp_npt_cycle.lammps`: Thermodynamic output generated by LAMMPS.
- `relaxed_simp_initial.data`: Atomic configuration after energy minimization.
- `after_300K_equil.data`: Configuration after the initial 300 K
  equilibration.
- `after_heating_1850K.data`: Configuration after heating to 1850 K.
- `after_hold_1850K.data`: Configuration after holding at 1850 K.
- `after_cooling_300K.data`: Configuration after cooling to 300 K.
- `final_simp_npt_cycle.data`: Final atomic configuration after the complete
  thermal cycle.

### Analysis scripts

- `1.py`: Extracts thermodynamic quantities from the LAMMPS log file and
  divides the data into different thermal-cycle stages.
- `plot_thermo_simp.py`: Processes and plots temperature, potential energy,
  total energy, pressure, and volume.
- `plot_rdf_simp.py`: Processes and plots radial distribution functions.
- `plot_msd_simp.py`: Processes and plots mean-square displacement.
- `analyze_structure_fraction_ovito.py`: Analyzes atomic structural fractions
  using OVITO.

### Processed source data

- `thermo_simp_npt_cycle.csv`: Thermodynamic data, including temperature,
  potential energy, kinetic energy, total energy, pressure, volume, and
  simulation-cell dimensions.
- `rdf_300K_equil.dat`: RDF data after equilibration at 300 K.
- `rdf_1850K_hold.dat`: RDF data during holding at 1850 K.
- `rdf_final_300K_hold.dat`: RDF data after cooling and final equilibration.
- `msd_1850K_hold.dat`: MSD data during holding at 1850 K.
- `msd_final_300K_hold.dat`: MSD data after cooling and final equilibration.

## 5. Running the simulation

Run the simulation from the `04_thermal_cycling` directory using:

```bash
lmp -in in.simp_npt_cycle
```

The LAMMPS input file reads the initial structure from:

```text
simp_20x20x20.data
```

and calls the trained potential using the relative path:

```text
../02_trained_potential/graph_200000.pb
```

The corresponding lines in the LAMMPS input file are:

```text
read_data       simp_20x20x20.data
pair_style      deepmd ../02_trained_potential/graph_200000.pb
pair_coeff      * *
```

## 6. Extracting thermodynamic data

Thermodynamic data can be extracted from the LAMMPS log using:

```bash
python 1.py \
  --input log_simp_npt_cycle.lammps \
  --output extracted_thermo \
  --timestep 0.001 \
  --natoms 16148
```

The thermal-stage durations used in `1.py` are:

```text
Initial 300 K equilibration:  20 ps
Heating:                     100 ps
1850 K holding:               50 ps
Cooling:                     100 ps
Final 300 K equilibration:    20 ps
```

The script generates the following processed files:

- `thermo_all.csv`
- `thermo_stage_average.csv`
- `volume_temperature.csv`
- `box_length.csv`
- `pressure.csv`

## 8. Raw trajectory

The complete raw LAMMPS trajectory file,
`dump_simp_npt_cycle.lammpstrj`, is approximately 349 MB. Owing to the GitHub
file-size limitation, the trajectory is archived separately in Zenodo:

[https://doi.org/10.5281/zenodo.22089925](https://doi.org/10.5281/zenodo.22089925)

The Zenodo record contains the compressed raw trajectory and its corresponding
metadata description.

## 9. Reproducibility

This GitHub repository provides:

- The initial atomic structure
- The trained deep potential
- The complete LAMMPS input file
- Representative atomic configurations at different thermal stages
- The LAMMPS thermodynamic log
- Data extraction and plotting scripts
- Processed thermodynamic, RDF, and MSD data

Together with the raw trajectory archived in Zenodo, these files enable
reproduction and verification of the thermal cycling results reported in the
associated manuscript.
